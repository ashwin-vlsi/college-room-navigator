# College Room Navigator

A web prototype for finding college exam halls/classrooms by room number.

## Features
- Search room number
- Shows building/block
- Shows floor
- Shows location description
- Mobile-friendly UI
- Room data stored separately in `rooms.json`

## Run locally
Open `index.html` with a local server (recommended), for example VS Code Live Server.
